k-belt {{ .Chart.AppVersion }} installed into namespace {{ .Release.Namespace }}.

Create a BestBefore policy to start rotating nodes (docs: https://k-belt.io):

  apiVersion: bestbefore.k-belt.io/v1alpha1
  kind: BestBefore
  metadata:
    name: default-pool
  spec:
    nodeClaimSelector:
      matchLabels:
        karpenter.sh/nodepool: default
    maxAge: 504h

Check on it with:

  kubectl get bestbefores

Helm does not upgrade CRDs. After upgrading this chart, apply the CRD yourself:

  kubectl apply -f https://raw.githubusercontent.com/rjbez17/k-belt/v{{ .Chart.AppVersion }}/charts/k-belt/crds/bestbefore.k-belt.io_bestbefores.yaml
